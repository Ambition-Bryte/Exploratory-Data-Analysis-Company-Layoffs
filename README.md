Exploratory Data Analysis – Company Layoffs

🧠 Project Overview

This project analyzes real-world company layoff data to uncover trends across industries, locations, and time periods. The objective was to generate insights that could support workforce planning and strategic decision-making.

🛠 Tools Used

SQL
Excel

📌 Analysis Steps

Cleaned and transformed raw layoff datasets using SQL
Grouped and aggregated data by industry, region, and year
Identified patterns, trends, and outliers
Prepared summary tables for reporting and visualization

📊 Key Insights

Identified industries with the highest number of layoffs
Observed layoff trends over multiple years
Highlighted regions most affected by workforce reductions

📁 Business Value

This analysis simulates a real-world business scenario where analysts are required to transform raw data into insights that inform strategic and operational decisions.
